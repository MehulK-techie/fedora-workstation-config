# fedora-workstation-config

Low-latency Fedora GNOME Workstation configuration repository featuring a floating translucent dock, instant fingerprint unlock, multi-workspace overview, top-bar fixes, and custom OCR utilities.

## Quick Setup on Target Laptops

git clone https://github.com/MehulK-techie/fedora-workstation-config.git
cd fedora-workstation-config
chmod +x setup.sh
./setup.sh
