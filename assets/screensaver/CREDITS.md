# Screensaver assets

`stan-lee-portrait.png`: Stan Lee at the 2014 Phoenix Comicon, photographed
by Gage Skidmore, from Wikimedia Commons
(https://commons.wikimedia.org/wiki/File:Stan_Lee_by_Gage_Skidmore_3.jpg),
licensed CC BY-SA 3.0 (https://creativecommons.org/licenses/by-sa/3.0/).
Changes: cropped to the head and shoulders, converted to grayscale, resized
to 320 x 400, and the backdrop removed to transparency. This file is shared
under the same licence. Web Hang samples it at run time: each window of the
tribute tower's portrait is one pixel of the photo.
